## 🚀 Local Development

### Prerequisites
- Node.js 20+
- npm

### 1. Install dependencies
```bash
npm install
```

### 2. Set up environment variables
`.env.local` is already pre-filled. For a fresh clone, copy from example:
```bash
cp .env.example .env.local
# Then edit .env.local with your values
```

Variables:
```
SITE_PASSWORD=MUM193746
AUTH_SECRET=<64-char hex string>
```

### 3. Process photos (run locally — not on Vercel)
```bash
npm run photos
```
This reads `source-photos/` and outputs WebP files to `public/gallery/` and writes `src/data/gallery.json`.

> **Note:** `source-photos/` is in `.gitignore`. Run `npm run photos` once locally, then commit `public/gallery/` and `src/data/gallery.json`.

### 4. Run dev server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000)

## ✏️ Customisation

All copy is in **`src/config/site.ts`**:
- `motherName` — displayed name
- `fromNames` — your names (shown in footer)
- `birthdayMonth` / `birthdayDay` — birthday date
- `birthdayMessage` — the typewriter message on the birthday page
- `people.*.caption` — captions under each person's portrait card

### Add optional birthday music
If you place an MP3 at `public/music/birthday.mp3`, the birthday page will show a play/pause button automatically (the player component checks for this file).

## 🌐 Vercel Deployment

1. **Push your code** to a GitHub repository (make sure `public/gallery/` and `src/data/gallery.json` are committed).

2. **Import repo** on [vercel.com](https://vercel.com) → New Project.

3. **Set Environment Variables** in Vercel Project Settings → Environment Variables:
   ```
   SITE_PASSWORD = MUM191828
   AUTH_SECRET   = <your 64-char hex secret>
   ```
   > ⚠️ Never commit `.env.local` — it's in `.gitignore`.

4. **Deploy** — Vercel will run `npm run build` automatically.

5. Share the Vercel URL with Mum and tell her the password!

## 🔐 Security

- Password is **never hard-coded** in source — only in environment variables
- Login sets an **httpOnly, Secure, SameSite=Lax** cookie with HMAC-signed token (30-day expiry)
- All pages (except `/login` and API routes) are protected by **middleware**
- Site is **noindex/nofollow** — search engines won't index it
- `robots.txt` disallows all crawlers
